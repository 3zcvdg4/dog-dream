# 📋 A Dog's Dream - 1-2 周上线开发计划

**目标**：构建一个能在 1-2 周内展示的个人作品集网站，核心是流畅的狗狗视频交互体验。

**核心三大支柱**：
1. 🐕 狗狗的视频交互体验（走路 + 趴下 + 醒来 + 行为动画）
2. 🎨 表达个人审美的画面与排版
3. 💫 整体交互流畅合理

---

## 优先级框架

| 优先级 | 内容 | 周期 |
|--------|------|------|
| 🔴 P0 | 首页能正常加载，视频状态机稳定播放 | Week 1 |
| 🟠 P1 | 视觉效果优化（梦泡、布局、颜色） | Week 1 |
| 🟡 P2 | 作品内容填充和自适应布局 | Week 2 |
| 🟢 P3 | 深梦页面、交互动效（后续迭代） | 待定 |

---

## 🔴 Phase 1: 首页 MVP（Week 1 — 优先完成）

### 1.1 视频状态机实现【第 1-2 天】

**当前状态**：🚧 正在实现

**目标**：确保视频播放和状态切换正常工作

**任务清单**：
- [ ] 在 `index.html` 中新增主 `video` 元素和梦境二级页面容器
- [ ] 在 `styles/main.css` 中增加 `video-overlay`、`hidden`、`disabled-click` 样式
- [ ] 定义状态机：`initial-play`、`dream-page`、`wakeup-play`、`interactive`、`sleeping`
- [ ] 实现初始视频播放（走→趴），不允许点击停止
- [ ] 通过 `video.onended` 判定初始播放结束，显示梦泡
- [ ] 在多端浏览器测试（PC、平板、手机）

**验证检查**：
- [ ] 控制台无错误信息
- [ ] 初始视频自动播放，点击无法暂停或跳过
- [ ] 视频播放结束后显示梦泡
- [ ] 梦泡浮动正常，不闪烁

**相关文件**：
- `index.html` — 新增视频元素、二级页面容器
- `styles/main.css` — 视频覆盖层、状态显示/隐藏、指针事件控制
- `js/interactions.js` — 状态机、按钮逻辑、`video` 播放控制
- `js/config.js` — 新增视频路径和状态时间配置

**技术细节**：
```javascript
// 状态流转
initial-play → dream-page → wakeup-play → interactive → sleeping → initial-play

// 视频管理
- initial: 走路→趴下视频，播放中禁用点击
- wakeup: 醒来动画视频
- interactive: 行为动画片段
- sleeping: 睡觉动画视频
```

### 1.3 醒来动画与交互状态【第 3-5 天】

**目标**：实现 `wakeup` 播放与后续交互

**任务清单**：
- [ ] `wakeUp()` 切换 `video.src` 为醒来动画
- [ ] 播放完成后进入 `interactive` 状态
- [ ] 在 `interactive` 状态显示行为按钮和 `sleep` 按钮

- [ ] 实现 `sleep` 重置逻辑

**可调整的参数**（在 `js/config.js`）：
```javascript

VIDEO_WAKEUP_SRC       // 醒来视频路径
VIDEO_SLEEP_SRC        // 睡觉视频路径
VIDEO_BEHAVIOR_SRCS    // 行为动画片段数组
```

**相关文件**：
- `js/interactions.js` — 状态机逻辑、视频切换
- `js/config.js` — 视频资源配置
