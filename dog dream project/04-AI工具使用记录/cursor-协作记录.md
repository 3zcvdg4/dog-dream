# AI 工具使用记录

## 总体背景

在 Dogdream 这个项目开始之前，我已经持续用 AI 做生图、文案、视频——但都是局部工具，没有串成一条链。2026 年 4 月 WorkBuddy 是**这个网站**的起点，之后主力转到 Cursor。

## 工具清单

| 工具 | 阶段 | 用途 |
|------|------|------|
| **WorkBuddy** | 2026-04 起点 | 第一个网站雏形；早期画廊 `scene-gallery.js` 参考 |
| **Cursor** | 2026-04 至今 | 主要协作：代码、Three.js、CSS、DEVELOPMENT_PLAN 维护 |
| **VS Code / Codex** | 中间过渡 | 工具链切换期间尝试 |
| **Gemini** | 素材 | 家狗照片 + 参考图 → 多视图与动作 |
| **即梦、Runway 等** | 素材 | 狗狗视频生成，多版测试 |
| **FFmpeg** | 素材 | webm 导出 |
| **html2canvas** | 转场 | 首页快照 → 涟漪转场 |

## WorkBuddy → Cursor 的切换原因

- 更新后变卡、变慢、生成失败
- 上下文混乱
- API 地区限制、网络、中转、价格等环境成本
- 大量时间花在「让工具能工作」而非设计上

## Cursor 协作习惯（后期建立）

1. **审美微调**：「标题字距再紧一点」「梦泡下移 30px」
2. **3D 场景**：走廊灯光、画框材质、烟雾、脚印
3. **文档同步**：每次决策写入 DEVELOPMENT_PLAN.md
4. **边界控制**：「只改 X，不改 Y」「定稿 / 回退 / 已确认」
5. **回退点**：`backups/checkpoint-*` 补丁

## 失败与归档

| 方案 | 结果 | 原因 |
|------|------|------|
| 纯 CSS 白圈涟漪 | 放弃 | 白叠白对比不足 |
| CSS 快照扰动（无真实捕获） | 放弃 | 视觉不成立 |
| 平滑滚轮惯性 | 回退 | 滑动掉帧 |
| canvas 去黑底 4.25.mp4 | 替换 | 放大发糊 |
| 狗狗 3D 模型 | 放弃 | AI 生成角色资产不稳定 |
| 多版 AI 视频 | 大量废弃 | 好看但无法嵌入网站 |
