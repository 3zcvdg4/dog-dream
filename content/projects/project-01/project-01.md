# Dogdream：个人网站搭建过程

## 一、开始

我是一名设计师，工作原因经常需要找一些设计素材，也会顺手打开很多设计师、艺术家或者独立开发者的个人网站。

有些网站做得很好，会让人多看几眼。不是那种作品很多，而是整体的感觉、交互方式或者排版，会让你觉得「这个人真厉害」。

看多了之后，自己也会偶尔想过要不要做一个个人网站。不过因为不会写代码，自己手上的作品也还不太多，觉得好像也没到能认真做一个网站的程度，就一直也没用真正的动手。

后来开始慢慢用一些 AI 工具。像 GPT、Midjourney 这些，其实算是比较早一批在用的。平时会用来做图、写文案、生成一些视频内容。但这些工具一直是分散的，各做各的，没有真正连成一条完整的创作流程。

我一直有一个比较实际的感受是：这些东西是可以串起来的，但我当时做不到。卡点主要还是在代码上。所以「做一个自己的网站」这个想法，一直都在，但也一直没真正开始。

直到后来机缘巧合下有个朋友推荐了 WorkBuddy，是我第一次接触到 Agent 工具。然后就算真正开始做这个网站。

最开始其实没有想「要做成什么样」，更多是先试一下这个工具能不能把想法跑起来。WorkBuddy 很快帮我搭了一个很简单的雏形。能跑起来的时候其实是有一点惊讶和兴奋的，因为之前很多事情在我这里是「做不了」的状态，现在突然变成「可以先出来一个版本」。

但这个状态没有持续两天。WorkBuddy 版本更新之后开始变得不太稳定，速度变慢，生成也经常出问题，整个流程开始变得反复。于是就开始寻找合适的工具。WorkBuddy、VS Code、Cursor、Codex 都用过一段时间，每个工具都有一段时间能用，但都不算稳定。因为有很多很现实的问题，比如 API 地区限制、账号购买、网络不稳定、价格、Agent 的上手难度这些。很多时间其实不是在做设计，而是在「让工具终于能工作」的痛苦中。最终是使用 cursor 会员，加 vscode + api 完成了这个网站的搭建。

这个阶段真的很感谢那些愿意解答我的问题的朋友们。

## 二、设计理念

这个网站最开始，其实并没有「走廊」，甚至没有完整结构。只有一个很模糊的画面：一只睡着的狗，一个坐垫，舒服的发梦。

我一直很喜欢那种安静、留白、像凌晨一样的氛围。不想做太强烈的赛博朋克，也不想做特别炫技的科技感，因为梦在我想象里，应该是安静的。

后来，「进入梦里」这个概念开始慢慢往下长。于是开始有了走廊，有了无限向前的空间，有了两侧漂浮的画框。它们不像普通项目入口，更像记忆碎片。每一幅画后面，都是一个过去做过的项目；点击它的时候，进入一个个梦景。

## 三、首页

首页的想法很简单。我喜欢狗，我也养了一条小狗，我想，要不就让他代替我来讲解作品吧，于是就有了首页的画面：全屏白色画布，衬线大写标题「EVERYTHING YOU SEE IS PART OF A DREAM」、梦泡、坐垫，和一只会走过来、躺下、入睡的狗狗。

首页的狗狗，是我遇到的第一个难点。

原本是想做成 3D 模型的。但后来尝试了好几种方法后发现，至少以当前 AI + 我的能力，很难稳定生成真正能用的角色资产，于是最后改成了视频方案。

制作过程大致是这样：

1. 先画布局、草图，确定元素排版与文案。
2. 找狗狗的风格参考。
3. 用自己家狗狗的照片配合参考图，在 Gemini 里生成多视图和不同动作。
4. 从里面挑一些状态，去不同的视频生成平台反复测试，即梦、Runway 等视频生成 AI 工具。最终选定了即梦的首尾帧功能，试了很多版。其实很多视频都很好看，但因为关键词不太准确，且即梦固执地认为狗狗的鼻子应该是黑色的，导致很多好看的动作都无法用上。
5. 视频出来后需要考虑浏览器兼容，就开始处理：剪影剪辑、AE 扣透明底、边缘、压缩、使用 FFmpeg 转 WebM。
6. 交给 Agent 嵌入网站、调尺寸落点、时序、自适应。

## 四、走廊页面

走廊页面其实在一开始做的时候，和 Agent 一起探讨时就有讲过我想要的大概风格。探讨完之后，第一次用 WorkBuddy 生成网站，居然把我想要的雏形做出来了，所以当时是很惊讶的，也确定了这个网站能做下去的决心。

制作过程：

1. 搭建基础走廊场景，建立无限延伸规则。
2. 设计画框结构与排列逻辑动画。
3. 调整镜头位置、透视关系和滚动速度。
4. 适配移动端与不同分辨率。
5. 丰富画框样式，打灯，增加烟雾、流光特效。

## 五、聚焦页面

聚焦页的设计理念很简单，走廊负责浏览，聚焦页负责停留。

用户点击画框之后，不会直接进入项目详情，而是先来到聚焦页。

这一页更像一个过渡空间，让用户从浏览状态切换到阅读状态，同时也能突出当前项目本身。

最难的点在于制作画框的特效。

制作过程：

1. 设计项目主视觉展示区域。
2. 设计项目标题与简介排版。
3. 设计进入详情页的交互方式。
4. 调整与走廊页面之间的过渡动画。
5. 优化移动端阅读体验。

目前这一页其实经历过很多次调整，因为一直在寻找一个平衡点：既要保留网站整体氛围，又要保证项目内容足够清晰。

## 六、三级页面（详情页）

详情页因为在我看来，这里展示的不只是项目结果，还有项目背后的过程。

所以最终决定把项目拆成：设计思路、制作过程、遇到的问题、最终成果。

让用户不仅能看到作品，也能看到它是怎么被做出来的。

制作过程：

1. 详情页规则文档制定
2. 分析项目风格与制作模版
3. 设定项目逻辑
4. 填充文字与图片
